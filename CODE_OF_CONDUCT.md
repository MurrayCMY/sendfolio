# Code of Conduct

We want SendFolio to be a friendly place to learn, build and ask questions.

- Be kind and patient. Assume good intent; disagree about ideas, not people.
- Welcome newcomers, and write in plain language. Not everyone is a native English speaker.
- No harassment, discrimination or personal attacks.
- Keep discussion on topic and constructive.

Maintainers may edit or remove comments, close issues and block people who do not follow these rules.
To report a problem, contact the maintainers through a private GitHub message or the repository's security contact.

This summary is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which applies in full.
